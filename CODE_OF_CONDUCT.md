# Code of conduct

Abode to Web aims to be a respectful, practical, and welcoming place to build reliable open-source software.

## Expected behavior

- Be patient, specific, and constructive.
- Critique ideas and code without attacking people.
- Welcome questions and different experience levels.
- Credit other people's work and respect licensing.
- Protect privacy; do not post credentials, personal information, or sensitive security details.
- Accept maintainer decisions about safety, scope, and project direction without harassment.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, doxxing, deliberate intimidation, sustained disruption, impersonation, and retaliation are not acceptable. Publishing another person's private information or vulnerability details without a reasonable safety purpose is also unacceptable.

## Scope

This policy applies in repository issues, pull requests, reviews, and other spaces where someone is representing Abode to Web. It also applies to private project communication.

## Reporting and enforcement

For immediate abuse on GitHub, use GitHub's built-in content reporting tools. For a project-level conduct concern, use the **Conduct contact** issue form to request a private channel. Do not include names, evidence, or sensitive details in that issue.

Security vulnerabilities use the separate private process in [SECURITY.md](SECURITY.md). Private vulnerability reporting should not be used for an unrelated interpersonal dispute.

The maintainer will review reports as confidentially as practical and may remove content, close or lock a thread, issue a warning, limit participation, or permanently ban a participant. Decisions consider impact, context, pattern, and the safety of the community. Retaliation against a reporter is prohibited.
